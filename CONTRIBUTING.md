# Contributing

Otwórz issue opisujące problem i zakres zmiany, następnie pull request.
Nie dołączaj danych konta ani rzeczywistych plików użytkownika. Używaj
syntetycznych danych w testach. Zachowaj minimalne uprawnienia dodatku i
zakaz przekazywania tokenów przez Native Messaging.

Uruchom `bash scripts/test.sh`. Zmiany protokołu, limitów, uprawnień,
obsługi OAuth i subprocess muszą mieć testy odpowiednich błędów i granic.
Opis PR powinien wyjaśniać zmianę zachowania, walidację i ograniczenia.
